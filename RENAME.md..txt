Quantum-Enhanced Protein Binding-Site Prediction Using Qiskit

Project Overview

This project applies quantum machine learning to protein binding-site prediction. The COACH420 protein dataset is processed to identify binding and non-binding residues. A classical Support Vector Machine (SVM) is compared with a Quantum Kernel-based SVM implemented using Qiskit.

Problem Statement

Protein binding-site prediction is important for understanding how proteins interact with ligands and can support drug discovery research. This project explores whether a quantum kernel can provide useful classification performance compared with a classical SVM.

Dataset

* Dataset: COACH420
* Protein structures: 420 PDB files
* Total residue records: 119,143
* Binding residues: 21,608
* Non-binding residues: 97,535

Binding residues were labelled using the minimum distance between protein residues and ligand atoms, with an 8 Å distance threshold.

Features

The model uses two features:

* Amino acid code (aa_code)
* Number of atoms (num_atoms)

The target variable is:

* label = 1 → Binding residue
* label = 0 → Non-binding residue

Classical Machine Learning

A classical SVM with an RBF kernel was used as the baseline model.

The dataset was balanced using:

* 400 binding samples
* 400 non-binding samples

A protein-level train/test split was used to reduce data leakage between training and testing proteins.

Quantum Machine Learning

The quantum model uses:

* Qiskit
* ZZFeatureMap
* FidelityQuantumKernel
* SVM with a precomputed quantum kernel

The quantum kernel maps the input features into a quantum feature space and calculates similarities between samples.

Results

Model	Accuracy	Precision	Recall	F1-Score
Classical SVM	58.24%	60.00%	37.04%	45.80%
Quantum SVM	53.53%	51.56%	40.74%	45.52%

The classical SVM achieved higher accuracy, precision and slightly higher F1-score. The Quantum SVM achieved higher recall, indicating that it identified a slightly larger proportion of binding residues in the test set.

Quantum Computing Component

The main quantum component is the Qiskit quantum kernel. The feature vectors are encoded using a quantum feature map, and the resulting quantum kernel is used by an SVM classifier.

This demonstrates the practical integration of quantum machine learning into a protein-related classification problem.

Install the required Python packages:

Generate features:

Run the classical SVM:

Generate the final comparison:

Conclusion

This project demonstrates a practical comparison between classical and quantum-kernel-based machine learning for protein binding-site classification. The Quantum SVM successfully integrates Qiskit into the workflow and provides a different classification behaviour, particularly in recall. Future work can include richer structural features, larger quantum-compatible datasets, and execution on real quantum hardware.
